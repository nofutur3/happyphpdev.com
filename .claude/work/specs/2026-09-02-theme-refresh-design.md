# Theme refresh: minimalist-professional with cyberpunk accents

## Goal

Replace the stock `gatsby-starter-blog` visual theme with a more professional,
readable design that carries a light cyberpunk/Matrix accent, without going
full dark-mode. Also fix real layout bugs found along the way (broken
responsive grid, `position: fixed` footer, unstyled prev/next nav,
inconsistent post-list markup between the homepage and category/tag pages).

## Non-goals

- No dark mode / theme toggle (light-first only, per decision).
- No "recent posts" sidebar list — Categories list only, to keep the sidebar
  minimal and avoid two overlapping "browse" widgets.
- No content/IA changes beyond what's needed to render nav + categories in
  the sidebar (no new pages, no changed URLs).

## 1. Design tokens (colors & type)

Rework the CSS custom properties in `src/style.css`:

- Background: near-white (`#fafafa`). Body text: near-black (`#161a16`).
- Accent (Matrix green), two shades:
  - `--color-accent`: a phosphor green tuned for AA contrast on white
    (~`#0a8f4f`) — used for links, hover states, small UI accents.
  - `--color-accent-bright`: a brighter neon green (~`#00ff9c`) — used only on
    dark surfaces (code blocks, small badges) where it won't fail contrast.
- Body font: **Inter**, self-hosted via `@fontsource/inter`, replacing
  `typeface-merriweather`. Line-height tuned to ~1.65 for prose.
- Monospace accent font: **JetBrains Mono**, self-hosted via
  `@fontsource/jetbrains-mono`, replacing `typeface-montserrat`. Used for:
  h1–h3 and the site title, nav labels, post meta (date/category/tags), and
  code blocks.
- Code blocks (Prism): replace `prismjs/themes/prism.css` with a custom
  dark theme — near-black background, green/white token colors. This is
  where the Matrix reference gets to be literal, since a terminal-styled
  code block fits its content.
- Keep the existing `--spacing-*` scale in `src/style.css`; retune heading/
  paragraph/list margins for Inter instead of Merriweather (sans generally
  wants slightly different rhythm than serif).

## 2. Layout & sidebar (`src/layouts/base.js`, `src/components/bio.js`, `src/components/footer.js`)

- **Fix responsive grid bug**: sidebar/content columns are currently
  `col-2`/`col-10` with no breakpoint prefix, so they never stack and get
  crushed on narrow viewports. Change to `col-12 col-md-3` /
  `col-12 col-md-9`.
- **Fix footer bug**: `footer { position: fixed; }` in
  `src/styles/global.scss` currently overlaps page content on short pages.
  Replace with a standard sticky-footer flex layout (`body` as flex column
  with `min-height: 100vh`, main content area `flex: 1 0 auto`) so the
  footer sits at the bottom in normal flow. Restyle footer text as small
  monospace, muted color, top border instead of a solid background block.
- **Sidebar additions**:
  - Nav links: Home, RSS feed link — terminal-prompt styled (e.g. `> home`),
    monospace, small text.
  - Categories list: query `allMarkdownRemark` grouped by
    `fields.category` (Gatsby's `group` aggregation) in `bio.js`'s existing
    `useStaticQuery`, render links to the existing `/category/<name>/`
    pages generated by `gatsby-plugin-categories`. This is the only new
    data dependency — no schema changes needed.
  - Keep avatar + name + summary as-is content-wise, restyle spacing/
    typography to match new tokens.

## 3. Article page polish (`src/templates/blog-post.js`, `src/style.css`)

- Post header: title uses the mono heading font; meta line becomes a single
  terminal-style line, e.g. `// 2026-09-02 · php` (monospace, muted color),
  replacing the current bare `<p>{date}</p>`.
- Prev/next nav: move the current inline `style={}` object in
  `blog-post.js` into CSS classes, style as two terminal-arrow links
  (`← previous`, `next →`) with hover accent color.
- Retune paragraph/heading/list spacing for the new sans body font so
  vertical rhythm is consistent (this is the direct fix for "vertical
  rhythm of texts is broken").
- Blockquote keeps its left-border accent, recolored to the new green.

## 4. Post list unification (`src/pages/index.js`, `src/components/post-list.js`, `src/components/post-list-card.js`)

- `src/pages/index.js` currently hand-rolls its own `<ol>`/`<article>`
  markup instead of using the existing `PostsList`/`PostsListCard`
  components (those are only wired up on category/tag pages today).
  Update `index.js` to use `PostsList`, so homepage/category/tag pages
  render posts identically.
- Restyle `PostsListCard`: drop the `react-bootstrap` `Card` wrapper (its
  default chrome looks generic and clashes with the new minimal design) in
  favor of a plain `<article>` block: title in mono heading font, a
  monospace meta line (date · category), excerpt in body font, green
  accent border-left and hover state, "Read more" as a text link (not a
  Bootstrap button).
- `index.js`'s current GraphQL query for posts must be checked against
  what `PostsList`/`PostsListCard` expect (`fields.slug`, `frontmatter`,
  `excerpt`) — align field selection if needed, no schema changes.

## 5. Dependencies (`package.json`, `gatsby-browser.js`)

- Remove: `typeface-montserrat`, `typeface-merriweather`.
- Add: `@fontsource/inter`, `@fontsource/jetbrains-mono`.
- Update `gatsby-browser.js` imports accordingly; swap the Prism theme
  import for the new custom dark theme (added under `src/styles/`).

## Verification

No test suite exists for this project (`npm test` is a stub per
`CLAUDE.md`). Verification is manual:

- Run `npm run develop` (or the existing Docker `app` service).
- Check in-browser: homepage, a single post, a category page, a tag page —
  at both desktop and mobile widths.
- Confirm: footer no longer overlaps short pages, sidebar stacks correctly
  on mobile, categories list links resolve, code blocks render with the
  new dark theme, prev/next nav is styled, homepage and category pages
  render posts with identical markup/styling.
- Run `npm run build` to confirm the production build succeeds (font
  package swap, GraphQL query changes).
